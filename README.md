# Data-Analyst-project_1
__Retail Business Performance & Profitability Analysis__

1. Project Overview


The Retail Business Performance & Profitability Analysis project analyzes retail sales data to understand business performance, identify profitable product categories, and improve inventory management.

This project uses Python, Pandas, SQL, and data visualization techniques to generate meaningful business insights from retail transaction data.

2. Project Objective

- Analyze retail sales and profit data.
- Identify the most profitable product categories.
- Compare sales performance across different regions.
- Analyze monthly sales trends.
- Calculate profit margins.
- Identify slow-moving products.
- Provide data-driven suggestions to improve business performance.

3. Technologies Used

- Python – Data analysis and processing.
- Pandas – Data cleaning and manipulation.
- Matplotlib – Data visualization.
- SQL – Querying and analyzing retail data.
- Tableau – Creating interactive dashboards.
- CSV Dataset – Storing retail transaction records.

4. Dataset Description

The project uses a sample retail transaction dataset containing 500 records.

The dataset includes the following columns:

- Transaction ID
- Order Date
- Region
- Product Category
- Product Name
- Quantity
- Unit Price
- Unit Cost
- Discount Rate
- Sales
- Cost
- Profit

Note: The dataset is generated sample data for educational and demonstration purposes.

5. Project Workflow

1. Import the retail dataset.
2. Examine the dataset and identify missing values.
3. Clean the data and handle missing records.
4. Calculate total sales, total cost, and profit.
5. Analyze profit margins by product category.
6. Compare sales across regions.
7. Analyze monthly sales trends.
8. Create charts to visualize business performance.
9. Write SQL queries to answer business questions.
10. Prepare a dashboard and project report.

6. Profit Calculation

Profit = Total Sales − Total Cost

Profit Margin (%) = (Total Profit / Total Sales) × 100

These calculations help measure business profitability.

7. Project Results

The analysis of the sample dataset produced the following overall results:

- Total Sales: ₹24,11,965.31
- Total Profit: ₹7,62,778.44
- Overall Profit Margin: Approximately 31.62%

The project also compares category-wise profit, region-wise sales, and monthly sales trends.

These results are based on the generated sample dataset and do not represent a real business.

8. How to Run the Project

Step 1: Install Python

Install Python on your computer.

Step 2: Install Required Libraries

Open your terminal and run:

pip install pandas matplotlib

Step 3: Download the Project

Download or clone this GitHub repository.

Step 4: Run the Python Program

Run the following command from the project folder:

python retail_analysis.py

Step 5: Check the Outputs

The program generates cleaned data, summary CSV files, and charts in the "outputs" folder.
